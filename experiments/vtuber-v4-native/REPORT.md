# 原生动作参考连续专家：研究记录

本实验将原生手臂动画用于示范和训练，增加动作相位输入，回归与四步 Flow 各训练 5000 步。固定完整台词预览改善了抬臂幅度，但实时短句的腕部变化范围仅 0.182，未通过挥手检查；其他失败见 `failures/`。Flow 左臂抬起仍不足。

1440 短片、240 多句序列的真实音频及 Cubism 参数记录验证见 `dataset-verification.json`。数据没有真人动作监督，离线误差与手工目标相似不能证明自然度。

未通过连续手部质量验收，不晋升默认。后续 r2/r3 权重与失败记录独立保留，当前候选改为模型选择完整动作组，见 `../vtuber-v4-gesture-groups/REPORT.md`。
