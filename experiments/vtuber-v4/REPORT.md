# v4 初版：保留的失败实验

本目录不再作为当前候选，默认 v3 没有切换。

初版数据作者使用整数默认数组建立连续动作，写入的小数手臂、眼睑等值被截断。虽然专家完成训练、HTTP/音频链路和持续运行测试通过，这些结果不能证明模型学会身体动作。独立的表情覆盖数组是浮点数，因此 16 组用户选择仅用于表情覆盖强度校准，不能用作身体动作偏好。

数据、权重、日志和旧对比均保留；未覆盖原始资产、v3 或语音权重。修正后的数据为 `datasets/vtuber-v4-body-float`；当前候选与完整验证见 [克制候选报告](../vtuber-v4-restrained/REPORT.md)。
