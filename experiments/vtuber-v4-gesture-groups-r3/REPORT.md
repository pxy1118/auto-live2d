# 原生屈肘位置的张掌挥手

用户要求移除双臂庆祝，问候采用“指出重点”的手臂位置，换成张掌再挥动，并强调抬起过程的关节合理性。本版据此更换身体执行曲线，候选入口独立指向本目录，v3 默认入口与原始资产保留。

## 实现与范围

问候直接使用原生 `竖手指切出来动画` / `竖手指切回默认` 的肩、肘、透视与接缝时序，在进入、保持、退出阶段均保留。关闭 Movement3 的食指绘制，使用正常张掌，只在手腕叠加小幅挥动，手臂上举方向保持在原生曲线的同一分支。三种编排均为右手同一屈肘姿态：双挥配轻歪头、点头后短挥、停留后慢挥。

此前负向前臂加独立上臂插值的问候已移除。辅助摊手等变体也改用原生点题关节曲线，并在左侧按参数镜像映射；不再独立拼接肩肘目标。抚胸与狗尾草仍保留各自原生曲线。渲染序列包含进入、挥动与收回，不只检查终点姿势。

cheer 已从七组动作列表、页面、工具 Schema 和 Python 调用示例删除。保留旧神经检查点的 9 维类别布局以兼容权重；若胜出类别是 cheer，输出 none、门控与动作置信度归零，不通过重新归一化将其他动作抬高。浏览器也把旧/迟到 cheer 预测转为空动作，显式 cheer 指令返回无效动作错误。其他情绪与开心表情仍可正常输出。

## 验证与限制

- TypeScript 32 项单元测试与构建通过，包含全阶段问候/点题肩肘一致、张掌绘制、退休动作及迟到预测保护。
- Python 17 项测试通过，包含退休类别胜出、置信度不重新归一化、检查点布局兼容，以及原有数据与流式专家测试。
- 7×3 段实际 Cubism 参数/画面记录，60 Hz 执行、30 fps 视频。与上一版轨迹输入完全相同的 10 段复用既有实际采集，其余重新采集，输入哈希与来源单独保存。
- 连续画面检查覆盖问候抬起阶段 0～1.25 秒、挥动和退出。实际参数记录中问候与点题参考的肩/肘轨迹逐帧比较，绘制模式与手腕运动分别验证。
- 真实音频播放期间，三种问候均保持原生点题肩肘参数，掌心可见，手腕变化范围约 0.32～0.40；手型为张掌，停止后收回。原生抚胸/狗尾草切换、暂停、释放和取消也通过。此检查在版本号提升前的开发构建中完成，身体执行源码与发布构建一致。
- 发布版进一步验证实际 TTS/语义动作选择、界面与动作清单，并保留原始结果及版本号。没有将以前的十分钟或时延测试改写为本版结果。

渲染与曲线检查用于发现错误，不能替代用户对自然度的评价，也不能证明人体运动学已完整建模。当前仍为未通过主观验收的候选，不晋升旧默认。原 16 组评分和第 14 组 B 保留，旧庆祝视频仅作为历史文件，不再出现在活动展示中。
