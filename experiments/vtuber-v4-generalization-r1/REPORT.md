# 语义容量与泛化对照实验

固定新版数据、任务查询头结构和训练配方，对比 0.8B / 4B 与最后 16 词元平均 / 完整词元注意力。每组使用三个相同随机种子，共 12 次训练；候选按开发集均值选择，采用中位种子，测试集仅评估一次。此对照的 0.8B 平均组使用本轮统一的任务查询头，不是旧 r2 的 MLP 选择器。输入维度不同，适配层参数量也随骨干变化。

| 骨干 | 特征 | 新场景宏 F1 | 开发集综合分 |
|---|---|---:|---:|
| Qwen/Qwen3.5-4B | full_attention | 0.8880 | 0.8596 |
| Qwen/Qwen3.5-4B | tail16_mean | 0.8029 | 0.7709 |
| Qwen/Qwen3.5-0.8B | full_attention | 0.7218 | 0.7172 |
| Qwen/Qwen3.5-0.8B | tail16_mean | 0.7074 | 0.6678 |

这些数值是三个种子的开发集均值，不是整体自然度或开放域泛化保证。数据为编写的合成监督，三个历史增强不独立；训练/验证分别有 2127/411 个不同台词与语境组合，新的最终测试有 125 个组合、30 个场景家族，共 381 条历史增强记录。原 v2 测试标签未进入训练。

选定候选的最终门控提议召回率：手势 79.0%、身体 73.1%、情绪 88.2%、特殊眼型 91.7%。身体动作提议误触发率 15.3%，超过 4% 目标；手势和身体召回率也略低于目标。当前未通过质量门槛，未切换默认。不会依据这些终测错误重调本检查点或改写测试标签。

运行时让 4B 语义规划与 TTS 共用 CUDA，原 0.8B 连续专家留在 CPU。CPU 语义预热与 TTS 合成重叠；分句计划提前提交并按真实音频起始时间触发，不依赖首个连续轨迹是否迟到。v3 及流式 r2 指针保留。

新的热服务、新台词延迟检查：首音中位数 564.9 ms，较同条件基线增加 126.7 ms，含会话建立增加 176.0 ms；动作更新 P95 97.0 ms。一组预热排除，三组不同台词配对测量；样本量有限。

十分钟检查实际运行 600.1 秒，覆盖 56 个分句，双臂同时抬起采样为零。55 项 TypeScript、21 项 Python 测试和生产构建通过。六段两句开发示例记录真实音频与 Cubism 参数，并重渲染为带声音的视频；不是盲测，也没有机器填写的评分。

此前时序修正前的运行、参数和视频保留在 before-early-plan 相关目录。完整元数据、全部种子权重、特征缓存、代码指纹及失败终测记录保留。本版仍是研究候选；下一轮需在训练/开发数据上处理身体误触发、监督多解和更自然的组合，再使用新的独立终测与人工偏好验收。
