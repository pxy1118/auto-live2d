# 原生28维情绪与动作

当前运行时 `v6.4.0-acting-feedback`。目标是输入台词后连续说话、随语义变化表情与动作；Qwen TTS音色保持原样。本轮没有接入DeepSeekharness；已新增原生面部形变与情绪身体配方，见 [表现设计](emotion-acting.md)。

分类器28个sigmoid分数独立保留。阈值转成表达证据，不合并6类、不把分数归一化到总和1。这些是模型分数与表演强度，不能当成人类真实情感的绝对量尺。

每个标签维护快响应response与慢心情mood；相反情绪出现时快响应更快释放，短暂中性语句承接先前心情，静默逐渐衰减。表情读取 `0.75 × response + 0.25 × mood`，直接映射到28个形变profile，不再叠加脸部指数平滑。人工覆盖进入/释放仅做一次过渡，neutral能覆盖表情和特殊眼型；自动曲线在底下继续推进，释放后回到当前状态。

表情、wink时序、导演保持、动作与片段共用同一时钟增量：播放由实际音频进度推进，缓冲（包括首音前）和暂停全部冻结，空闲允许自然收势和情绪衰减。音频时长修正只移动未来观测，已发生的分句不重放。跨语音单元保留心情，取消清空未来事件。

动作输出为 `performance.plan.v4`：一个action及其置信度。它可以是none、7种包含身体节拍的协调手势、9种独立身体动作；没有body_overlay。调度器统一处理优先级、去重、忙碌、冷却和替换退出，采样器只执行已有曲线。手势退出已经混合背景姿态，身体偏移仅叠加一次。

预取只准备情绪观测与分句语义特征。真正开口后，事件头读取当前64维affect（28快+28慢+tension+VAD+intensity+3风格）和26维纯动作历史；不再每句重新构造500ms假状态，不再把旧7情绪或12面部值混入动作历史。连续背景每400ms更新24帧9通道，复用当前分句的0.8B特征。400字语音单元和最多240字语义分句相互独立，逗号观测不会重启TTS。

扩展接口：

- `contracts/emotion-bindings.json`定义全部28标签的 expression_profile、通用动作试演配方与描述。眼睑点缀绑定到具体动作变体；本轮训练后目录有17种可选动作。
- `ActionRegistry.register`可注册未来片段，phase只能使用已知手势或身体原语；所有片段仍走统一调度器。
- 运行目录注册不等于模型已经学会该ID。当前模型有17个输出，未来注册动作可由导演调用，历史以显式untrained槽编码；自动选择新ID需要扩展输出并重新训练。
- 旧27情绪段、预览与训练入口快照位于 `research/emotion-catalog-r1-archive/`，不进入默认目录或训练目标；主界面只有新的折叠试演入口。

训练结果、数据指纹和验证边界见 [r3报告](../experiments/vtuber-v6-acting-feedback-r3-final/REPORT.md)。语音音色、0.8B编码器和分类器均冻结，只有轻量事件头重训；连续背景头原字节复用。
