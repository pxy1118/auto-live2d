# 连续情绪与量化边界

运行时 `v5.1.0-emotion-curves`。分类器、动作模型与 Qwen TTS 均在 GPU；分类器保留 FP32，复用已有权重，不新增大模型或训练。

## 为什么改

逐句选择一个标签并替换表情会丢失混合情绪，也会在句号或分类波动处突然换脸。现在把分类结果当作时间轴上的观测，用连续状态决定实际表现。

1. 在短语边界批量获取 28 个独立 sigmoid 分数，保留原始值。当前短语带上前一短语作为有限因果前文，避免把夸奖后的“不好意思”切成孤立道歉；跨音频单元同样承接上一段实际台词。引号及其后续归属说明保持在同一观测中，较长无标点文本使用有界窗口。观测不读取未来短语，`window_text` 记录实际分类窗口。
2. 按作者发布的标签阈值生成连续目标：`e = gain × 0.9 × sqrt(max(0, (p - threshold) / (1 - threshold)))`。组内取最大证据，避免 happy 的标签更多而天然占优；组间总量超过 1 时等比缩放。阈值处没有旧式固定 0.35 幅度跳变。默认 gain 为 1；本角色对 remorse（内疚/歉意）的表达增益为 0.25，仅给轻微忧心，避免“不好意思”同时出现 remorse 分数时直接变成大幅哭泣；sadness/grief 的增益不变。这是显式表演映射，不改写原始概率。
3. 为六类可表达情绪维护较快反应与较慢心境，两层均采用保留位置、速度的临界阻尼曲线。默认快速层占 75%、心境层占 25%。短暂中性不会立刻清空已有情绪，连续同类观测也不会重启曲线。明确正负转折加快旧反应退出，慢速心境仍有余韵。
4. 主标签采用竞争余量和持续时间迟滞，只是当前曲线的摘要。渲染与动作使用完整混合权重，不因摘要标签变化而清空曲线。

时间常数、混合比例与迟滞参数集中于 `src/emotion-curve.ts` 的 `emotionCurvePolicy`，属于当前表演策略初值，未经人类自然度偏好标定。时间常数不是“到该毫秒已完成切换”的承诺。

## 时间与通道归属

情感观测与动作语义句、TTS 音频单元独立。新增逗号内的情感观测不会新增合成请求。按字符位置占比近似映射到实际音频，最终音频长度可修正未来边界，已通过的观测不重放；当前没有逐词对齐。

只有实际音频播放才能推进说话中的曲线，暂停、缓冲及预取不推进。连续语音单元保留情绪位置和速度；自然结束后逐渐衰减。显式取消清理未来观测和心境，晚到结果不能重新激活。

普通笑容、眉形、嘴形及效果叠图由情绪层统一拥有。背景动作模型不能提前使用整段台词中的未来情感抢写表情。连续动作的现有情绪条件输入读取同一播放状态的混合权重。显式导演优先，释放后返回仍在演进的自动状态；语音口型、眨眼、眼皮开合、衣着、动作曲线和物理继续由各自原有模块负责。

## 量化了什么

- `affect.source.probabilities`：分类器当前短语及有限前文窗口的 28 个分数；对应文本保存在 `affect.source.window_text`。独立多标签，不要求总和为 1；它们是文本分类置信分数，不是人类真实感受的强度量尺，也未在本角色中文直播场景做概率校准。
- `affect.target`：阈值映射后的表达目标，是可调表演策略。
- `affect.response` / `affect.mood`：快速反应和较慢心境的连续状态。
- `affect.weights`：最终多情绪表达权重，表情和动作共用。
- `affect.vad`：由六类权重与显式原型投影得到的愉悦度、激动度、主动性；不声称该分类器直接预测 VAD。

可以量化比较表达连续性、主标签切换次数、曲线斜率、转折响应时间与帧率一致性。要评价识别是否正确，仍需要独立标注的中文场景集；要评价自然度，需要真实观看评价。本次功能与数值检查不替代这些评价。
