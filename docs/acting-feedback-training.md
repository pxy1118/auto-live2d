# 动作反馈实现与训练

2026-11-07，运行时 `v6.4.0-acting-feedback`，最终候选 `vtuber-v6-acting-feedback-r3-final`。本轮只训练约 33 万参数的事件头，语义编码器、28 类情绪分类器、9 通道连续背景头和 Qwen 音色冻结。

## 动作与表情

| 反馈 | 当前实现 |
| --- | --- |
| 放心、释然时抚胸 | 复用完整原生 `chest`；释然试演绑定抚胸。模型也学习放松轻摇的不同句式。 |
| 反对时摇头，允许与抬手同时进行 | 新增不抬手的 `shake`；原有 `refuse` 继续在一条协调曲线里同时竖指、摇头。 |
| 灵光一现时竖起手指 | 复用 `point`，领悟试演绑定该手势；模型学习领悟词在句内的位置。 |
| 紧张、害怕时减少手势并轻颤 | 新增 `tremble`，三个有限变体，身体收住并以小幅偏移颤动，保持双手放下。 |
| 亲昵时扭动明显一些 | 增强 `cajole` 的前倾、重心与身体轻扭，仍为有限动作，结束自然回收。 |
| 期待陪伴时眨眨眼 | `cajole/C` 到位后双眼连续眨两次；显式 `double_blink` 也可调用。 |
| 得意时前倾邀功，或后仰昂首 | 新增 `proud`：A 前倾轻扭＋双眨眼；B 后仰抬下巴＋右眼 wink；C 挺身停留。 |
| 好奇时靠近凝视、歪头；肯定时点头 | 复用 `lean/C`、`tilt/C`、`nod/A`，增加对应监督，避免用致谢手势代替。 |
| 减少反复致谢 | 补充非感谢场景的正负样本，并将 `thanks` 同动作重复窗口设为 24 秒。 |

只新增摇头、轻颤、得意三个通用身体原语。目录现在是 none＋7 个协调手势意图＋9 个身体原语，共 17 个选择；仍由一个调度器管理所有权。原生手部接触位置不随强度缩放，绘制图层保持互斥。当前模型缺少掌心翻转绑定，招呼仍是点头倾身。

自动播放严格执行动作头的选择，已移除选完动作后按情绪再次替换身体动作的逻辑。情绪资源绑定中的 `action` 供显式试演和评分候选探索使用。双眨眼/wink 由已执行的动作变体触发，笑、害羞或得意分数本身不会自动触发 wink；表情层仍独占眼睑，语音独占嘴部开合。

## 句内时机

新计划为 `performance.plan.v4`，使用 `onset_fraction`（0～0.95）表达动作关键位置在当前语义句中的比例。播放时将它投影到音频时长，并按原生抬手或身体准备时间提前入场。前一动作未结束时，后一句意图进入现有单一队列，等待安全退场；切句或语音结束会丢弃未执行的过期意图。模型不再因当前忙碌就抹掉新反馈句的未来动作。计划记录保存目标音频时刻、实际开始、准备时长与时长是否已最终确定。

这依然是按文本位置估算的音频同步，没有新增逐词强制对齐模型。训练中的位置误差是句长比例误差，不能称为逐词时间精度。暂停与缓冲仍冻结同一表演时钟，逗号不拆成独立 TTS。

## 数据与标签来源

冻结数据位于 `datasets/acting-feedback-r3f/`，不随公开仓库分发：

- 7,374 条已有合成动作监督，沿用原有语义组划分。
- 3,096 条按反馈设计的合成文本、历史状态和动作位置样本。
- 从 15 条明确动作备注解释出的 90 条监督样本，加上 18 条前句准备样本，全部在训练集。动作意图来自明确备注；具体变体、力度、时长和句内锚点仍是助手编写，不能当成人工认可的动作捕捉标签。
- 总共 10,578 条：训练 7,836、验证 1,368、测试 1,374。每个文本模板、前缀和历史变体同组；分组与规范化同文检查没有跨集合泄漏。

99 个已评分样本、104 份评分文件继续保留原样，相关 500 个原始文件有哈希清单。A/B/C 原来共享表情，且动作配方已经改变，所以原始候选选择仍只作审计，不直接监督新动作的逐帧参数。“都不合适”没有转换成 none 标签。

15 条明确备注原话参与了训练，回放 15/15 只证明已知反馈被学会，不是独立验收成绩。用于报告泛化的测试集未参与训练、模型或阈值选择。输入情绪仍来自冻结分类器的原始分数与因果曲线，未用练习场景标签替换。

文件包括 `records.jsonl`、`preferences.jsonl`、`acceptance.jsonl`（内部 `use=training_replay_only`）、`source-hashes.json`、`manifest.json` 和特征缓存。脚本拒绝覆盖指纹不同的数据快照。

## 训练与评价

训练 3 个随机种子，每个 2,400 步。从 r2 迁移已有权重，扩展三个动作输出及 26 维纯动作历史；第三个数值输出重新学习句内位置。通过验证集选择种子、步数和触发门槛，额外约束旧场景中性误触。最终为种子 7137、第 2400 步、统一门槛 0.5。连续背景检查点与 r2 保持逐字节一致。

| 同一扩展测试集，1,374 条 | r2 | 最终候选 |
| --- | ---: | ---: |
| 17 类宏平均 F1 | 0.4902 | 0.7763 |
| 中性样本误触率 | 10.43% | 3.04% |
| 错触发致谢率 | 0.377% | 0.151% |
| 句内位置平均绝对误差 | 0.3183 | 0.0721 |

旧有的 906 条测试子集另列，避免新增动作使基线不可直接比较：14 类宏平均 F1 从 0.7271 到 0.6725，中性误触从 3.88% 到 3.17%。说明、点头等旧小类存在召回损失，需要后续补充；不能宣称所有动作均改善。新测试中的 shake、tremble、proud F1 分别为 0.909、0.974、0.923；这是合成监督测试成绩，不代表用户自然度评分。

更激进的 r3b 和逐动作阈值探索保留实验记录，最终没有采用。逐动作校准在未见场景上漏掉轻颤，因此最终运行仍用一个动作头与统一门槛。

```bash
# WSL，使用项目的 latent 环境；已完成的训练目录拒绝覆盖
python latent/build_acting_feedback.py
python latent/train_acting_feedback.py
python -m unittest latent.test_emotion_catalog latent.test_emotion latent.test_acting_feedback
```

重新训练需要冻结数据、原 r2 特征及模型资产。生成新的数据版本使用 builder 的 `--out`，训练默认使用上述冻结快照；已完成实验需用 trainer 的 `--out` 指定新目录。旧 r2/r3 候选不会被重写。

## 验证与边界

`npm test` 覆盖有限姿态、摇头/颤抖、前后倾、双眨眼、动作所有权、句内锚点、暂停及嘴型所有权。`npm run test:feedback` 在真实 Cubism 模型上测量 16 组动作、1,920 个手部图层状态，检查实际网格位移、独立眼睑与自然回收，并输出正常速度演示视频。`tests/feedback-speech-browser.ts` 检查 GPU 模型、原 Qwen 音频和最终执行动作，使用的是已知反馈原话回放。

本轮没有训练情绪分类器；含蓄情绪误判、句首感情迟到仍可能影响面部表现。当前音频映射也没有逐词对齐真值。后续优先收集新版实际播放中的满意动作和时机标注，同时补充旧说明/点头场景；自然度仍需用户再次观看。

实际语音联调另修复启动就绪判定：只有动作与 Qwen 都就绪时才启用播放，避免 TTS 尚在加载时报告可播放。

最终真实语音回放共 7 段通过，含句内反对、释然抚胸、领悟竖指、紧张轻颤、陪伴双眨眼、得意昂首和跨句释然。90 项 TypeScript/接口检查通过；数据完整性检查覆盖原始 500 文件哈希。
