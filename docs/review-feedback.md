# 首轮人工反馈与表演校准

本文保留 2026-11-06 的审阅证据；保留动作反馈已在 v6.4 实现并训练，见 [后续实现](acting-feedback-training.md)。

2026-11-06，运行时 `v6.3.2-feedback-acting`，检查点仍为 `vtuber-v6-native28-motion-r2`。本轮读取用户标注、修正渲染与手势资源使用，没有重训模型。

## 数据核对

读取 108 个创建过的样本，其中 99 个有人工评分，覆盖 98 个练习场景；共 104 个不可变评分文件，统计采用每个样本的最新评分。41 条有文字备注。选择为 A 7、B 2、C 15、差不多 58、都不合适 17。96 个已评分样本来自 `v6.3.1-hand-drawings`，另 3 个来自修复前 `v6.3.0-preference-review`，后续数据导出需区分版本。

99 份评分均引用三个完整播放的 take，音频哈希相符。审阅只读原数据，保存了 500 个相关 case/rating/take 文件的 SHA-256；详细文字和播放证据见 `test-results/review-feedback/audit.md`、`audit.json`。可复跑：

```powershell
python -X utf8 scripts/audit_performance_feedback.py
```

A/B/C 原本共享表情曲线，主要比较动作变体、力度与起点。因此“差不多”不是表情满意标签，“都不合适”也不是动作 none 标签；这些数据仍然 `training_ready=false`。

## 已修正的表现层问题

| 反馈 | 证据与处理 |
| --- | --- |
| 好好笑为什么 wink；害羞段 wink 不合时宜 | `amusement-01`、`context-09`、`context-06` 均记录了自动 wink。移除 amusement/love 的自动绑定，保留用户认可的 pride wink 及显式左右 wink 指令。 |
| 失望、难过、后悔仍然看着观众 | 旧配方的向下视线仅约 -0.16～-0.18，乘以较弱情绪后只有 -0.03～-0.15。提高到 -0.6～-0.7，配合眼睑低垂和眉嘴变化。后悔改为侧下方回避，紧张加入有停留的侧视变化；全部使用表演时钟，暂停不偷跑。 |
| 好奇眼神不明显 | 放大双眼睁开幅度，视线目标回到正前；保留现有身体动作选择规则。 |
| 黑脸淡、脸红和泪眼不明显 | 黑脸使用 0/1 绘制开关，加上不同的开启/关闭阈值及短暂停留以防闪烁。脸红、泪眼和冷汗仍可连续变化，提高可见度。显式黑脸指令和最终参数组合也执行同一开关规则。 |
| 右手半抬像手背朝前 | wave、explain/B、refuse/B 把竖食指的关节轨迹与默认手背图层拼接，冒充张掌。已移除拼接；说明与拒绝使用完整原生手型。当前资产未找到可验证的掌心翻转输入，wave 暂以点头倾身招呼，能力接口公开此限制。真正掌心朝前挥手需要补绘制/绑定。 |
| 手势力度变化使姿势不对 | 直接缩放绝对肘角让抚胸变成悬空举手、指点只抬一半。现在保持原生接触/指点姿态，力度改变身体和腕部等附加动作。保持此前的手型互斥与不透明规则。 |

这次改变的是渲染配方，不改变分类器原始 28 分数、快慢情绪曲线、事件模型动作 ID、Qwen 音频或语音嘴型所有权。动作头的 `wave` ID 保留其招呼意图，实际能力说明与播放记录明确写出当前身体替代动作；没有伪称素材已支持翻掌。

## 识别问题需要单独处理

原始播放记录表明，一部分不满意发生在表情输入之前：

- `sadness-01`：“大家都离开以后，这里突然变得好安静。”主要是 neutral，后半句还出现 relief，几乎没有悲伤证据。
- `grief-02`：“那是我们最后一次见面，可当时谁也不知道。”两段都主要是 neutral。
- `embarrassment-01`：被夸后“不知道说什么”被识别为 confusion/annoyance。
- `fear-02`：“这里太黑了，你能走在我旁边吗？”主要是 neutral/curiosity。
- `nervousness-02`：“希望我等会儿不会说错话”被识别为 optimism。
- 上半句情绪迟到：当前分类窗口只含当前及前一个短语。后文才揭示情绪时，前半句不会提前获知。`grief-01`、`nervousness-01` 都存在这种情况。

本轮没有用练习场景名字覆盖模型结果，也没有把这些含蓄句全部硬改成悲伤/害羞。下一步需从明确备注整理句内情绪、对象与时间范围的人工校准集，单独比较完整句输入、语境处理和中文阈值；其中否定、转述和情绪转折必须保留验证集。满意动作样本需等资源配方稳定后再筛选训练。

## 保留的动作设计反馈

以下建议已收录，尚未声称实现：放心/释然时抚胸；反对时在对应词处摇头；领悟时竖指；紧张和害怕的细微颤抖；亲昵时更大的身体轻扭；渴望时双眼快速眨动；得意的前倾邀功/后仰抬头；减少反复使用致谢手势。当前拒绝原语已有协调摇头和抬指，本轮修正手型，具体语词对齐仍需动作时机校准。

## 验证与使用

功能测试覆盖无泛化 wink、保留得意 wink、视线回避/低垂、黑脸开关滞回、原生手型和接触姿势、暂停和嘴型所有权。实际模型检查另见 `test-results/review-feedback/acting/` 与 `hand/`；前后对照位于 `before/`、`after/`。静态试演和运行回归不能代替用户对自然度的再次评价，也不代表上面的识别问题已经解决。

刷新网页后使用新版。旧评分及其原始 take 全部保留；源代码指纹改变后，要观看新的表现需重新准备候选，无需重标旧的 99 个样本。
